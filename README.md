# YouTube Bot Dashboard (static UI)

This repository contains a static HTML/CSS dashboard mockup for a YouTube download and edit bot. There is no backend functionality—open the page locally to view the design.

## Quick start
1. Clone or download this repository.
2. Open `index.html` in your browser (double-click or use a local server such as `python -m http.server`).
3. Explore the sections for overview, queue, presets, and activity log.

## Project contents
- `index.html` – page structure and sample content.
- `style.css` – dark-themed styling, layout, and responsive tweaks.

## Notes
- All data is placeholder for UI demonstration.
- No external build steps are required.
